Task Parameter Help:
https://cybertec-postgresql.github.io/pg_timetable/latest/components/#parameter-value-format 
 
BUILTIN:
When using some BUILTIN commands then some parameters don’t need to be in a JSON format.
 
Example:
Command: Sleep
Parameter:
20
 
SQL:
With the SQL command you pass parameters using $1 $2 etc..
SQL: SELECT * FROM TableXYZ WHERE Col1 = $1
Parameter:
["Value1"]
 
PROGRAM:
When running programs that have parameters, put them in JSON format.
 
Example:
Command: D:\PostgreSQL\Backup\Test.cmd
Parameters:
[
      "aaa",
      "bbb",
      "333"
]
 
To run a PowerShell script, just put powershell in the Command and the script name and parameters in Parameters.
You need to cater for special characters like slash \
 
Example 1: Runs the PowerShell script Test.ps1
Command: powershell
Parameters:
["D:\\PostgreSQL\\Backup\\Test.ps1"]
 
Example 2: Runs the PowerShell script Test.ps1 with the parameter “start”
Command: powershell
Parameters:
["D:\\PostgreSQL\\Backup\\Test.ps1 start"]
 
Example 3: Runs the PowerShell script Test.ps1 with an alternative way to pass multiple parameters.
Command: powershell
Parameters:
[
      "D:\\PostgreSQL\\Backup\\Test.ps1",
      "param1",
      "value2"
]
